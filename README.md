# 🎨 Visual Vibes – Wallpaper Discovery App

**Visual Vibes** is a modern and elegant mobile application designed to bring stunning, high-resolution wallpapers to your fingertips. Built with Flutter and powered by Supabase, the app offers a seamless browsing experience and allows users to explore, preview, set and download a wide range of wallpapers across various categories.

---

## 📱 Features

- 🌈 **Extensive Wallpaper Collection** – Curated high-quality wallpapers in multiple categories.
- 🔍 **Search Functionality** – Quickly find wallpapers by keywords or tags.
- 💾 **One-Tap Downloads** – Save your favorite wallpapers locally with ease.
- ❤️ **Favorites Section** – Bookmark wallpapers for quick access.
- 🖼️ Set as Wallpaper – Apply any wallpaper directly to your mobile screen.
- ⚡ **Fast & Smooth UI** – Built using Flutter for cross-platform performance.

---

## 🛠️ Tech Stack

| Technology     | Usage                          |

| Flutter        | UI development (cross-platform)|
